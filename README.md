# Hello World Test 1 — Lịch sử giao dịch (Tìm kiếm)

Expo (React Native) app implementing MoMo **transaction search** screens from Figma node `10132:53944`, styled with MoMo UI Kit tokens.

## Screens / states
1. **Gợi ý + lịch sử tìm kiếm** — chips + recent queries
2. **Kết quả** — e.g. query `nạp` → matching transactions
3. **Empty** — “Không tìm thấy kết quả”

## Run
```bash
npm start
```
